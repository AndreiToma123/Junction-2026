Valio Aimo Junction 2026 Challenge (0.1.0)

Download OpenAPI specification:Download

Use on-demand apis to query for dynamic data such as price and availability. File download apis will provide data sets needed in the challenge. The files do not change during the challenge unless announced separately.

Note that solutions should not be based on frequently retrieving prices and availabilities for all products. In real world that would not be feasible since prices and availabilities are customer specific in this B2B scenario and they will constantly change. Query the APIs only when you have narrowed down the products that you are interested in based on static product data. Undisclosed rate limits are in place for the APIs

Availability

Tells whether the products can be delivered on the requested date and how much is available.

Request: customer, requestedDate (your desired delivery date) and products (list of 1 - 1 000 product codes)

Limit: a request can contain at most 1 000 products. A longer list is rejected with HTTP 422. Query only the products you need.

In reality, availabilities are customer specific so passing in a different customer number can return different response for the same product / date combination. In this challenge, however, customer number does not affect response so you can pass in whatever.

Response

Field Meaning
timeNow Server time when the answer was produced (Helsinki time).
requestedDate The date from the request, at midnight.
products One entry per requested product, in request order.
productId The product code.
closingTime The order cut-off time (= order by closingTime at the latest to receive goods on availableDate)
salesBlock If true, Product cannot be ordered currently
logisticModel Stock products are stocked by us, so we know their available quantities. Terminal products are delivered from supplier's warehouses and we don't know the actual available quantities
scheduleLines If product is available, array has exactly one entry. Empty array means product cannot currently be delivered on any date
scheduleLines[].availableAmount Quantity available, in salesUnit. For Terminal products this is always 999999 since actual value is not known. 0 means not available.
scheduleLines[].availableDate Earliest date when amount is available. Note that this might differ from your requestedDate
scheduleLines[].salesUnit Technical code of sales unit
scheduleLines[].salesBlock If true, product cannot be ordered currently

Price

Returns the price of the products for the customer on the requested date.

Request: customer, requestedDate (=the desired delivery date of the products) and products (list of 1 - 1 000 product codes).

Limit: a request can contain at most 1 000 products. A longer list is rejected with HTTP 422. Query only the products you need.

In reality, prices are customer specific so passing in a different customer number can return different prices for the same product / date combination. In this challenge, however, customer number does not affect response so you can pass in whatever.

Response

Field Meaning
customerId The customer id from the request. Not meaningful in this challenge.
currency Currency of all prices.
pricingDate The date the prices apply to (the requested date).
products One entry per requested product.
quantity Quantity the price is for (always 1.0)
catalogPrice Price per sales unit before tax. value is without tax, valueWithTax with tax.
priceWithTax The price including tax, with its validity period.
comparisonPrice Price per comparisonUnit (for example per kg) so products of different size can be compared.
comparisonUnit Unit of the comparison price. Only KG (kilogram) and L (litre) are used
tax taxRate (percent) and taxValue (the tax amount in currency).
listPrice Price before the customer-specific price or discount
validFrom, validTo Period on which the price is valid
netPriceFound True when a customer-specific net price was found, false when the catalog price was used
error True when no price could be found for the product
